# API reference

These links open the generated C# reference after you build the DocFX site. The generated API navigation lists the remaining namespaces and types.

- [Smurfs domain](_site/api/Smurfs.Domain.html) contains Smurf, Village and Pet.
- [Smurfs business rules](_site/api/Smurfs.Domain.BusinessRules.html) contains the domain catalog.
- [Craft domain](_site/api/Craft.Domain.html) contains the reusable rule contracts and violation type.
- [Smurfs application use cases](_site/api/Smurfs.Application.Smurfs.html) contains the create and list commands and handlers.
- [Smurfs persistence](_site/api/Smurfs.Persistence.html) contains the app-data contracts.
